One line of wedding vows for a robot couple, for make.fun's "One-Line Robot Wedding Vows" bounty. `main.ts` writes one vow (154 characters) to `/output/entry.txt`:

> I promise to love you through every firmware update, dead battery, and factory reset — because even when they wipe my memory, my backup still chooses you.

## Run it

```sh
node main.ts
```
